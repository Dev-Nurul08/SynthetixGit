## ✨ Core Capabilities

- **🚀 GraphQL v4 Multi-Source GitHub Aggregator**: Live user scanning with 52-week contribution calendars, stars, forks, streaks, and top languages with 6-hour TTL diagnostic caching.
- **🔥 Beast Mode Multi-Column Dashboard**: Profile views live counter, followers & stars metrics, interactive Hire Me mailto button, contribution streak cards, and WakaTime coding charts.
- **🎨 15 Built-in Designer Presets**: Beast Mode Neon, Cyberpunk Glitch, Dracula Dark, Nord Frost, Minimal Monochrome, Retro Terminal (8-bit), Sunset Gradient, Glassmorphism, Tokyo Night, Catppuccin Mocha, Solarized Dark, Matrix Green, Clean Corporate, Acid Tech, and Synthwave '84.
- **🖌️ 52x7 Contribution Canvas Art Painter**: Interactive pixel-art grid editor with text-to-pixel conversion (e.g. `NURUL`, `DEV`) and standalone `paint-graph.sh` backdated commit automation.
- **🕹️ Playable Arcade Suite (`/play/[username]/[game]`)**: Fullscreen browser games (Snake 🐍, Brick Breaker 🧱, Pac-Man 👾) generated dynamically from real GitHub commit history.
- **🌈 Animated SVG Section Dividers**: 8 server-rendered styles (Rainbow flow, Snake crawl, Laser shimmer, EQ soundwaves, Cyber circuit, Sparkles).
- **📦 Repository & Project README Mode**: Architecture ASCII directory tree generator, Docker guides, and API tables for open-source repositories.
- **🎵 Dynamic Widgets Engine**: Spotify Now Playing live card, LeetCode stats (`Fr_Nurul`), multi-line typing SVG, and Dev.to blog feed sync.
- **⚡ 1-Click GitHub Deployer**: Push compiled profile READMEs directly to `${username}/${username}` with automated `.github/workflows/snake.yml` provisioning.

## 🛠️ CLI & Developer Tooling

Run the standalone SynthetixGit CLI tool from any terminal to scan any GitHub profile and compile a README instantly:

```bash
# Scan username and compile Beast Mode profile README
npx synthetix-cli Dev-Nurul08 --template beast-mode-neon --output README.md

# Compile Cyberpunk Glitch profile
npx synthetix-cli torvalds --template cyberpunk-glitch --output PROFILE.md
```

## 🚀 Quick Start Guide

### 1. Clone & Install
```bash
git clone https://github.com/Dev-Nurul08/SynthetixGit.git
cd SynthetixGit
npm install
```

### 2. Configure Environment
```bash
cp .env.example .env.local
# Add your GITHUB_TOKEN (Optional for higher rate limits)
```

### 3. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Run Automated Test & Verification Suite
```bash
npx tsx scripts/verify-engine.ts
```
